**Bistro Ember: Rush Hour** is an original, fast-paced top-down HTML5 Canvas cooking game built with zero external runtime dependencies and procedural WebAudio synthesis.

## Features

- **Live Kitchen & Order Rail**: Active customer tickets with urgency countdown timers, recipe badges, tip bonuses, and combo streaks.
- **10 Fresh Pantry Ingredients**: Brioche Buns, Aged Cheddar, Wagyu Patty, Vine Tomato, Crisp Lettuce, Caramelized Onion, Truffle Sauce, Fresh Pasta, Basil, and Garlic Butter.
- **Interactive Cooking Stations**:
  - **Prep Cutting Boards**: Animated knife chopping with progress meters and slice particles.
  - **Sizzling Grills & Skillets**: Dynamic cooking gauges (`Raw -> Seared -> Perfect -> Burned`), flames, smoke, and procedural WebAudio sizzle audio.
  - **Assembly Island**: Visual multi-layer dish stacking with live recipe match previews.
  - **Hot Pass & Golden Bell**: Glowing `READY TO SERVE!` plating counter with service bell chime.
- **Dual Input Support**: Full keyboard (`WASD` / `Arrows`, `Space` / `E` interact, `1-4` quick station dispatch, `Q` discard) and mouse click-to-move / click-station controls.
- **Deterministic URL Showcase Modes**: Supports `?shot=start|play|end&seed=1` (cover screenshot order: `1-play.jpg`, `2-start.jpg`, `3-end.jpg`).

## Local Play

Serve the `game/` directory with any static file server and open `index.html` in a modern browser.
